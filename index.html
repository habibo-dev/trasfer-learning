01 / Learning map

From pixels to transferable knowledge.

Transfer learning is easier to understand when you first see what a neural network learns at different depths.

01

Feature learning

Early convolutional layers often respond to simple visual patterns—edges, corners and textures. Deeper layers can encode increasingly task-specific patterns.

02

Knowledge reuse

A pre-trained backbone provides learned representations. A new prediction head maps those representations to the labels of a target task.

03

Domain shift

When source and target data differ, reused features may be less suitable. The size and nature of that gap help guide the strategy.

Scientific note: These are useful tendencies, not guarantees. Transfer performance depends on the source data, target task, architecture, training setup and evaluation protocol.

04 / Project workflow

Turn the concept into an experiment.

A credible comparison changes the training strategy while keeping the evaluation protocol consistent.

STEP 01

Define the task

Choose target classes and a dataset with a clear, documented split.

STEP 02

Set baselines

Compare a scratch model, frozen features and fine-tuning under declared conditions.

STEP 03

Evaluate fairly

Use the same held-out test set and report metrics such as accuracy and macro-F1.

STEP 04

Explain limitations

Discuss dataset size, class imbalance, domain gap, compute and uncertainty.

What to record
A useful experiment log
✓Dataset and source of data; class counts and split policy.
✓Architecture, pre-trained weights, input size and preprocessing.
✓Frozen/unfrozen layers, optimizer, learning rate and epochs.
✓Test metrics, confusion matrix and errors on difficult examples.
A good scientific question
Example for a Master’s project
“How does the amount of labeled target data and the source–target domain gap affect the relative performance of feature extraction and fine-tuning?”

Treat this as a research question. The answer must come from measured experiments, not from the illustrative interface.

Key ideas to remember
A compact mental model
01Pre-training: the model learns parameters from a source task or dataset.
02Transfer: reuse learned parameters or representations for a target task.
03Fine-tuning: continue training some or all pre-trained layers on target data.
04Evaluation: only an appropriate held-out test set can support performance claims.
